# План «Новий вигляд» — Первинний огляд (обговорено 06.11.2026)

## Порядок роботи
1. Швидке виправлення: масштаб аркуша при перетягуванні панелей (ResizeObserver замість window.resize; «По ширині / Весь аркуш / 100%»; вміст плаваючого віконця тягнеться по висоті).
2. Макети 3 екранів на погодження: пацієнти/старт, форма огляду зі схованим текстом, призначення (+ вигляд друку огляду).
3. Фундамент: шрифтова шкала 6–7 розмірів, кольори лише через змінні, відступи 4/8, один набір SVG-іконок (зі Skiagrama), прибрати !important і зайві z-index.
4. Каркас, компоненти, тексти, доступність — одним оновленням в окремій гілці, випуск один раз.

## Рішення
- Основа — ПК; телефон у цьому оновленні отримує лише нові кольори, шрифти, іконки.
- Колір — темно-синій #1D5B8A. Вигляд просторий. Анімацій мінімум (швидкість).
- Теми: світла, темна, «Теплий папір», «Кабінет». Вибір шрифту лишається.
- Друк і Word оновлюємо (вільні документи); бланки МОЗ не чіпаємо.
- Перемикач «старий вигляд» на перехідний час.
- Другий агент працює паралельно, але НЕ чіпає styles.css, body.html і файли інтерфейсу.
- Нова назва — пізніше.

## Каркас ПК
- Меню розділів зліва зі станом ✓ / ● (стан лише там, без повторів).
- Текст документа схований: кнопка «Текст» / Ctrl+Enter.
- Старт — останній пацієнт; список і пошук — із шапки (Ctrl+K). Екран «Сьогодні» — коли з'явиться дошка відділення.
- Перший запуск — один майстер з 2 кроків.

## Введення пацієнта
- «+ Новий» / Ctrl+N → курсор у ПІБ; стать сама з по батькові (позначка Ч/Ж, клік — виправити).
- Дата народження цифрами з маскою дд.мм.рррр, вік текстом.
- Одна кнопка «Імпорт ▾» (МІС, H24, закладка).

## Скарги — «розумна клавіатура» (офлайн)
- Текстове поле, підказки з 3 літер (сірим, Tab — прийняти; кілька — список ↑↓ Enter).
- Джерела: словник програми, власні часті фрази, обрана хвороба.
- Скорочення як у Skiagrama (редаговані).
- Автоматично: велика літера, крапка, пробіли, °C / мм рт. ст., кома між відомими скаргами; у вільному тексті — лише підкреслення.
- Медичний словник: помилка підкреслюється, виправлення — кліком. Знахідний відмінок після «Скарги на».
- Слова без дії лікаря не міняються. Чипи — згорнуті під полем.
- Той самий механізм потім — анамнез, щоденник, висновок.
- Якщо не друкую: чипи розгортаються при кліку на групу / «Вибрати зі списку»; групи за системами згорнуті з лічильником, відкрита одна; групи обраної хвороби — першими; програма запам'ятовує звичку (миша → чипи відкриті одразу).
- Синдроми — лише для введення: рядок синдромів над чипами, натиск → типові скарги вже позначені, зайве знімаю, «Готово». Набори редаговані.
- У документі — перелік конкретних скарг, упорядкований за системами без назв груп.
- Обрані синдроми підставляються в «Обґрунтування діагнозу» в епікризі.

## Ревізія шаблонів — уточнення
- НЕ вішати «перевірте» на всі поля. Виправити самі заготовки (аудит один раз, лікар переглядає один список змін).
- Позначка лише при справжніх суперечностях (короткий список несумісних пар: геміпарез + «стійкий у позі Ромберга», набряки + «набряків немає» тощо).

## Зручність (усе прийнято)
1. «Збережено ✓» у шапці.
2. Показники одним рядком (T, АТ, ЧСС, ЧД, SpO₂, вага, зріст, ІМТ), поза нормою — підсвітка.
3. «Норма» в кожному розділі, відхилення виділяються.
4. «Далі →» внизу розділу, Ctrl+↓ / Ctrl+↑.
5. «Скасувати» 10 с замість «Ви впевнені?» (питання — лише для незворотних дій); замінити 5 системних alert/confirm/prompt.
6. Рядок стану: пацієнт, день перебування, що не заповнено (клік — перехід).
7. Ширина полів за змістом.
8. Ctrl+K — пошук пацієнтів і дій.
9. Часті власні фрази — першими.

## Ревізія шаблонів хвороб
- Проблема: заготовка заповнює лише частину полів, решта лишається «норма» (напр. ішемічний інсульт: «У позі Ромберга стійкість збережена» при геміпарезі).
- Скрипт-аудит: для кожної хвороби — які поля «норма» лишились у системі, яку хвороба вражає → лікар переглядає список.
- Варіанти «не досліджувалось» / «неможливо через тяжкість стану» для проб (Ромберг, пальце-носова тощо).
- Правило: у вражених системах заготовка не лишає «норму» мовчки — поле позначається «перевірте».

## Діагнози НК 025:2021 (повний класифікатор)
- Зараз у програмі ~420 вибраних кодів МКХ-10.
- Підключення файлу класифікатора (JSON/CSV/XLSX) кнопкою → зберігається в IndexedDB, не роздуває HTML.
- Пишу код → бачу назву; пишу назву → бачу код. Вбудований короткий список лишається запасним.
- Джерело: meddata.pp.ua/data/classifications/nk-025-2021.json (неофіційне, звірити з офіційним НК 025:2021).

## Надійність і підтримка (додано 07.11.2026)
1. **Нагадування про резервну копію.** Раз на тиждень нагадує зробити експорт; якщо давно не робили — видно в рядку стану. Дані живуть у браузері, тож це головний ризик.
2. **Підказки замість довгої «Довідки».** Коротка підказка при першому відкритті розділу; повна довідка лишається в меню.
3. **Чорно-білий друк і щільніший текст бланків.** Для економії кольору й паперу при великих тиражах.
4. **Чистка зайвих шрифтів і стилів.** Видалити невикористані, щоб файл був легший і відкривався швидше на слабкому планшеті.
5. **Тексти помилок простою мовою.** Не «помилка збереження», а конкретна дія: «Спробуйте ще раз або експортуйте дані».
6. **Перевірка сценарію «огляд за 5 хвилин».** Наскрізний прохід від нового пацієнта до друку з таймером. Повторюємо після кожного етапу оновлення.
