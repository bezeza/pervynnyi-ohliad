# Специфікація: «Новий вигляд» 0.10 — Первинний огляд

Джерело рішень: PLAN-UI-0.10.md. Цей файл — короткі межі й критерії готовності для великого оновлення.

## Що змінюємо
- Вигляд екрана на ПК: токени (шрифти, кольори, відступи), каркас (меню розділів зліва, текст документа схований), компоненти, іконки одного стилю.
- Введення пацієнта й скарг за описом у PLAN-UI-0.10.md.
- Зручність і зменшення перевантаження (пункти зі списку в плані).
- Телефон — лише нові кольори, шрифти й іконки.
- Перемикач «старий вигляд» на перехідний час.

## Чого не чіпаємо
- Бланки МОЗ (003/о, 066/о, 003-4/о тощо): вигляд, розмітка, сітка.
- Логіка розрахунків, дози, шаблони хвороб (окрема задача: ревізія шаблонів іде своїм потоком).
- Збережені дані користувача: профілі, «Мої шаблони», налаштування, пацієнти.
- Другий агент: поки йде оновлення, не змінює styles.css, body.html і файли інтерфейсу.

## Межі
- Одна гілка на все оновлення, випуск один раз, коли всі критерії виконано.
- Кожен крок — окрема задача з тестом; тести мають проходити перед злиттям.
- Версія й запис у журналі змін — як у ZAVDANNIA.md.

## Критерії готовності
1. Макети 3 екранів (пацієнти/старт, форма огляду зі схованим текстом, призначення) погоджені лікарем.
2. Тести проходять; повний набір запускається перед випуском.
3. На ПК немає дублів кнопок із переліку вад у PLAN-UI-0.10.md.
4. Збережені дані відкриваються без втрат (перевірка на копії).
5. Друк бланків МОЗ порівняно зі старою версією: розмітка та розміри без змін.
6. Контраст тексту не нижчий за 4.5:1; кнопки на ПК не менше 32 px.
7. Перемикач «старий вигляд» працює.
8. Лікар підтвердив у роботі принаймні один повний огляд від початку до друку.

- Правила НСЗУ щодо послуг (чекаємо, поки визначаться).
