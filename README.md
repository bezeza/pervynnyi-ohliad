**Відкрити:** https://bezeza.github.io/pervynnyi-ohliad/

**Офлайн-файл (один HTML, працює без інтернету):** https://bezeza.github.io/pervynnyi-ohliad/pervynnyi-ohliad.html — відкрийте й збережіть сторінку («Зберегти як…»).

## Встановити як застосунок

- **Android (Chrome):** відкрийте посилання → меню ⋮ → «Додати на головний екран» / «Встановити застосунок».
- **iPhone (Safari):** відкрийте посилання → «Поділитися» → «На екран „Додому“».
- **Комп’ютер (Chrome, Edge):** значок встановлення праворуч в адресному рядку → «Встановити».

Після першого відкриття програма працює без інтернету. Коли інтернет є — сама підтягує нову версію.

## Дані пацієнтів

**Папка даних (Chrome або Edge на комп’ютері):** «Налаштування» → «Створити / обрати папку даних». Програма створить папку «Первинний огляд — дані» і сама зберігатиме туди пацієнтів (кожен окремим файлом), шаблони й налаштування. Після перевстановлення браузера чи на іншому комп’ютері достатньо обрати цю папку — усе підтягнеться.

Дані пацієнтів зберігаються **лише в браузері вашого пристрою** (база IndexedDB — тисячі пацієнтів без обмеження в 5 МБ). Програма не звертається до жодних сторонніх серверів: шрифти вбудовані у файл. На GitHub і в інтернет вони не передаються. Тут лежить тільки код програми.

- Робіть резервну копію: «Налаштування» → «Резервна копія: зберегти всіх у файл».
- Щоб перенести пацієнтів зі старого файлу чи іншого пристрою: збережіть копію там і відкрийте її тут («Відкрити пацієнтів з файлу»).

Програма готує текст документа; остаточне рішення та підпис — за лікарем.

## Для розробників

Програма для користувача — **один HTML-файл**. Вихідний код розкладено на блоки в `src/`, скрипт збирає з них готовий файл.

```
src/
  head.html, styles.css, body.html, tail.html   — оболонка сторінки
  manifest.json                                  — порядок блоків скрипту
  js/NNN-назва.js                                — блоки скрипту (спільна область видимості, порядок важливий)
     data-*.js     — дані: заготовки хвороб, препарати, схеми призначень і їх джерела, МКХ-10, ICPC-2, скринінги
     решта         — логіка й інтерфейс
build.mjs           — збирання → pervynnyi-ohliad.html (офлайн), index.html (сайт), версія кешу в sw.js
tests/              — автоматичні перевірки (jsdom)
```

```
npm install          # один раз
npm run build        # зібрати
npm test             # зібрати і прогнати всі перевірки (~5 хв); npm run test:quick — ~30 с
```

Правки робіть у `src/`, а не в `index.html` чи `pervynnyi-ohliad.html` — ці файли перезаписуються під час збирання. Версія — `VERSION` і `CHANGELOG` у `src/js/120-version-changelog.js`.

Медичний зміст (дози, схеми, критерії) змінюйте з посиланням на джерело: у `data-rx-sources.js` для кожної хвороби вказано настанови й рівень доказовості.
