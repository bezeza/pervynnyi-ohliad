# Первинний огляд

Генератор медичної документації для стаціонару й амбулаторного прийому: первинний огляд, щоденники, призначення, епікризи, консиліум, спільні огляди, направлення, довідки. Терапія, неврологія, хірургія, інфекційні хвороби, травматологія.

**Відкрити:** https://bezeza.github.io/pervynnyi-ohliad/

## Встановити як застосунок

- **Android (Chrome):** відкрийте посилання → меню ⋮ → «Додати на головний екран» / «Встановити застосунок».
- **iPhone (Safari):** відкрийте посилання → «Поділитися» → «На екран „Додому“».
- **Комп’ютер (Chrome, Edge):** значок встановлення праворуч в адресному рядку → «Встановити».

Після першого відкриття програма працює без інтернету. Коли інтернет є — сама підтягує нову версію.

## Дані пацієнтів

Дані пацієнтів зберігаються **лише в браузері вашого пристрою**. На GitHub і в інтернет вони не передаються. Тут лежить тільки код програми.

- Робіть резервну копію: «Налаштування» → «Резервна копія: зберегти всіх у файл».
- Щоб перенести пацієнтів зі старого файлу чи іншого пристрою: збережіть копію там і відкрийте її тут («Відкрити пацієнтів з файлу»).

Програма готує текст документа; остаточне рішення та підпис — за лікарем.
